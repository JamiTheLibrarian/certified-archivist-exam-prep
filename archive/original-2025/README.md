# Original App Code, 2025

Historical record of the original CA Exam Prep App's code. **This is not the code for the rebuild.** It is kept for provenance only, and nothing here runs: the question files it loads are not included, because unreviewed questions stay in Google Drive.

## Development history

| Dates | Where the app lived | What survives |
| --- | --- | --- |
| Apr 30 – May 3, 2025 | A React interface built by ChatGPT inside ChatGPT itself | Only the prototype screenshot in Drive; the code is redacted in the shared conversation |
| May 6, 2025 onward | A static HTML/CSS/JavaScript site in Replit, started from ChatGPT's code and continued with Replit's own assistant | The two ChatGPT versions below; the final Replit build is lost |
